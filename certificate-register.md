# Dev and Design Certificate Register

Public verification register of certificates issued by **Dev and Design HQ** for
the Agentic Software Engineering Workshop series.

To verify a certificate, match its ID against the tables below. An ID that does
not appear here was not issued by us.

Verification enquiries: learn@devdesignhq.com

---

## How the IDs are built

```
DDHQ - ASE - 01 - 001 - K7QM
 |      |     |     |     |
 |      |     |     |     verification code
 |      |     |     recipient number within that edition
 |      |     edition number
 |      Agentic Software Engineering series code
 Dev and Design HQ
```

The verification code is a random four-character string. It is there so that an
invented ID will not match this register. Characters that are easy to confuse
when typed by hand are not used.

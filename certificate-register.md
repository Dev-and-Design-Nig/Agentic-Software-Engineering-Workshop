## Verification & Authenticity Guidelines

Each Certificate Identification Number follows Dev and Design's verification schema:

$$\text{DDHQ} - \text{ASE} - \text{01} - \text{[Index]} - \text{[AuthCode]}$$

- **DDHQ**: Dev and Design Headquarter prefix
- **ASE**: Agentic Software Engineering Workshop code
- **01**: Edition / Cohort index
- **Index**: Sequential recipient number (`001`, `002`, `003`)
- **AuthCode**: Secure alphanumeric checksum / verification string

For verification inquiries or record amendments, contact the **Dev and Design** team.
